Babo Violent 2

The original 2.11, from its GPL source, running on gasm: the same openbv.wasm as on the desktop.

Controls: move with W A S D, aim with the mouse, shoot with the left button, grenades with the right, Tab for the scores, the backquote key for the console, Esc for the game's menu. Click the picture first so it gets the keyboard. Hold Esc for a second to stop the game. All controls.

To play: Host, then Start; pick a weapon, "Auto assign team", and shoot to spawn. Online games need the openbv server, which isn't there yet. Your settings stay in this browser. The game's art and sounds are RndLabs', from the source release.
